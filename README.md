# APEC WtE Public-Data Screening Pipeline

[한국어 안내](README_KO.md)

Status: **local publication candidate; not yet a public release**

This repository preserves selected code from a three-person international team research project on waste-to-energy (WtE) feedstock risk in South Korea, Indonesia, and Singapore. The original plan required common measured waste moisture and lower heating value (LHV) data. Because those measurements could not be obtained consistently across the three countries, the research question was narrowed to a public-data **screening and literature-scenario analysis**.

## What The Code Does

- combines country, municipal, waste-composition, weather, and WtE proxy data;
- builds relative feedstock-risk and literature-based LHV scenario tables;
- summarizes the Korea daily food-waste/weather regression;
- produces country, Indonesia municipality, and Singapore WtE result tables;
- generates SVG figures and the 2026-05-05 / 2026-05-11 integrated report outputs.

The screening score is not a measured-moisture predictor, a validated LHV model, a facility-efficiency model, or an optimal-siting tool.

Run both checks directly:

## Repository Map

- `scripts/`: eight byte-preserved historical processing and analysis scripts.
- `01_raw_data/`, `02_processed_data/`, `05_analysis_results/models/`: compact, non-personal derived inputs needed for the verified endpoint.
- `reference_outputs/`: frozen outputs generated by the two endpoint scripts.
- `metadata/`: code, input, output, and SHA-256 manifests.
- `docs/`: provenance, data-source, contribution, and limitation records.
- `verify_reproduction.js`: release-preparation verifier added on 2026-08-26; not historical research code.
