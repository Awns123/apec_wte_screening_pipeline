# File Selection

## Included Historical Code

Eight scripts were selected because they represent processing, analysis, audit, regression, and integrated-report stages. They are byte-identical to the archived copies.

## Excluded From The Public Candidate

- raw literature PDFs and extracted full text;
- chat exports, team contact information, and role-audit source messages;
- post-hoc reviewer/Codex audit and reconstruction scripts;
- duplicate ZIP files and duplicated code copies;
- folder-moving utility code that could alter an organized archive;
- live collection scripts with network drift or hard-coded local dependency paths;
- the incomplete student execution scaffold;
- manually written reports that the endpoint scripts do not generate.

Exclusion protects privacy and provenance. It is not evidence that omitted materials never existed or were unimportant to the research.
